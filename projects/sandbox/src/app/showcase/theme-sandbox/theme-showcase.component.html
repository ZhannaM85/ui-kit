How it works

  1. Every UI Kit component references var(--kit-color-*, fallback) in its styles.
  2. If no custom property is set, the fallback value is used — components look exactly the same as before.
  3. To theme the components, set --kit-color-* variables on :root, body, or any wrapper element.
  4. The variables inherit through the DOM, including through Angular’s view encapsulation, so all components pick them up instantly.
